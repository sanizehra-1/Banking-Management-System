# 🏦 Online Banking Management System

A desktop-based Java application built using **Java Swing** and **Object-Oriented Programming (OOP)** principles. This project models an online banking environment to manage accounts digitally

## 🚀 Key Features
* **Account Verification:** Compulsory account number validation before performing transactions.
* **Deposit Funds:** Securely add money to the account balance
* **Withdraw Funds:** Withdraw a specified amount subject to sufficient balance checks
* **Transfer Money:** Transfer funds to other accounts within the system using user IDs/account numbers
* **Balance Tracking:** View real-time current account balances

## 💻 OOP Concepts Applied
* **Abstraction:** The base `Gui` class defines abstract structures (`deposit` and `withdraw`) for transaction handling.
* **Inheritance:** `SavingsAccount` extends `Gui` to inherit core properties and implement specific banking behaviors.
* **Encapsulation:** Sensitive variables like account balance are protected and managed via secure getter and setter methods.

## 🛠️ Tech Stack & Tools
* **Language:** Java
* **UI Framework:** Java Swing (`javax.swing` / `JFrame`)
* **IDE / Environment:** NetBeans / compatible Java IDE
